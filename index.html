Generative UI codelabs

A2UI, AG-UI, MCP Apps, json-render, OpenUI Lang and a coding-agent harness, each in four modes: 24 runnable examples with code walkthroughs and recorded executions.

static: the model fills pre-built componentsdeclarative: the model composes from a catalogopen-ended: the model writes sandboxed HTMLmixed: a catalog plus one sandboxed region

Each page runs live against python serve.py. Opened from a static host, it replays the recorded run of the same page. Source and walkthroughs: GitHub repository.
